# Python PostgreSQL REST API

A hands-on backend development project built to learn Python, REST API development, database integration, and containerization.

## Tech Stack

* **Python** — Backend programming language
* **FastAPI** — REST API framework
* **PostgreSQL** — Relational database
* **SQLAlchemy** — Database interaction and ORM
* **Docker** — PostgreSQL containerization
* **Swagger UI** — API documentation and testing

## Features

* Connect a Python API to a PostgreSQL database
* Create and retrieve employee records
* Automatically create database tables
* Test API endpoints through interactive Swagger documentation

## Getting Started

1. Start PostgreSQL using Docker.
2. Configure the database connection in `.env`.
3. Install the required Python dependencies.
4. Run the FastAPI application.
5. Open `http://localhost:8000/docs` to explore and test the API.

## Learning Objectives

This project is part of my backend development practice, focusing on REST APIs, SQL databases, environment configuration, and Docker fundamentals.
